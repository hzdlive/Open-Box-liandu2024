# Open-Box 官方 vs 我方开源版相似度评估

**评估日期**: 2026-10-19
**对照基线**: 官方 v0.1.341（面板）/ v0.1.330（客户端）
**评估范围**: 闭源功能（路由器面板 + 客户端 App），不含已开源的 scripts/zashboard/sing-box

**评分说明**: 每项按"公开可观察行为"的复刻完整度打分。
100% = 黑盒测试无法区分；0% = 完全未实现。

## 结论

**总体相似度：约 64%**

- **面板端（用户日常用的）**：**82%**。订阅、分组、分流、DNS、故障转移等核心闭环已打通，今日新增的订阅出口、卡片展开、可用数修复等补齐了不少体验细节。主要缺口在规则穿透调试、内容过滤收尾、终端分流验证。
- **客户端 App**：**15%**。这是最大的短板，只有骨架没有实现。
- **诚实说明**：82% 的面板分是"公开可观察行为"层面。原版有些深层机制（如 direct-answer 的 DNS 钩子、内核热切换的精确时机）我们是架构替代实现，黑盒行为一致但内部不同。

**如果只算面板（用户在 VPS 上用的）**：**82%**，核心功能可用，细节持续补齐中。
**如果算完整产品（含手机 App）**：**64%**，客户端是主要拖累项。
